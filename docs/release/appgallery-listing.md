# 「短信快传」华为应用市场上架文案

> 提审时可直接复制到 AppGallery Connect 对应字段。

## 应用名称

- 主推：**短信快传**
- 备选：验证码快传、短信速传
- 注意：不能与在架 HarmonyOS NEXT 应用重名，创建应用时若提示占用则换备选。

## 一句话简介（应用简介）

将手机上的短信验证码和文本一键发送到 Windows 电脑，电脑端自动提取验证码、弹出通知并复制到剪贴板，免去手动誊抄。数据仅在局域网内直传，不上传任何云端服务器。

## 详细描述（可直接粘贴）

【产品介绍】

短信快传是一款手机与 Windows 电脑之间的文本快传工具。在电脑上登录网站或客户端需要手机验证码时，无需在两台设备间来回对照手动输入——通过系统分享将验证码发送到电脑，接收端自动提取验证码、复制到剪贴板并弹出桌面通知，登录时直接粘贴即可。

【核心功能】

- 验证码自动提取：电脑端自动识别消息中的验证码并复制到剪贴板
- 桌面通知提醒：消息到达即弹出系统通知，不打断当前工作
- 历史记录：保留最近 15 条消息，点击任意一条即可再次复制
- 局域网直传：手机与电脑在同一 Wi-Fi 下点对点传输，无需数据线
- 隐私安全：所有数据仅在本机与局域网内处理，不经过任何云端服务器，不收集任何个人信息

【使用方法】

1. 在 Windows 电脑上安装并启动「SMS Bridge Receiver」接收端（下载地址见"了解更多"）
2. 手机与电脑连接同一 Wi-Fi
3. 在短信等应用中长按文本，通过系统分享选择「短信快传」
4. 选择已发现的电脑发送，电脑端自动通知并复制验证码

【适用场景】

- 电脑登录网站、客户端时需要输入手机验证码
- 将手机上的链接、账号、口令等文本快速传到电脑

## 审核风险规避要点

1. **数据流向说明**：描述与隐私政策中明确"数据仅局域网传输、不上传服务器、不收集个人信息"——这是本应用的差异化卖点，也是通过隐私审查的关键。
2. **PC 端依赖说明**：明确写出接收端需单独安装及下载地址（填入 AGC"了解更多"官网字段，建议使用 GitHub Release 公开页面），避免被以"功能不完整"驳回。
3. **验证码合规表述**：强调文本由**用户主动分享**，应用不申请、不读取短信权限（可在描述中写明"无需短信权限，仅接收您主动分享的文本"）。
4. **平板适配**：module.json5 的 deviceTypes 含 tablet。若未做平板 UI 适配，建议首版先移除 tablet 只上手机，或确保平板上界面正常并准备平板截图。
5. **隐私政策 URL** 必须公网可访问，内容与描述中的隐私表述一致。
