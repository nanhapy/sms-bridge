# APP 备案材料（工信部 / 经 AGC 备案入口提交）

> 备案在上架前完成，未完成的应用会被 AGC 拦截。入口：华为开发者联盟 → 备案专区 / AGC 应用内“备案信息”。

## 一、基本信息速查（提交表单时对照填）

| 字段 | 填写内容 |
|---|---|
| 应用名称 | 青鸟传码 |
| 包名（Bundle Name） | `com.smsbridge.app` |
| 版本号 | 1.0.0（versionCode 1000000） |
| 应用平台 | HarmonyOS（APP） |
| 隐私政策 URL | `https://nanhapy.github.io/sms-bridge/release/privacy-policy.html` |
| 主体类型 | 个人（已完成华为开发者实名认证） |
| 是否提供互联网信息服务 | 否（纯局域网工具，无服务器、无网站） |
| 是否含用户注册/登录 | 否 |
| 是否涉及新闻、出版、教育、医疗、金融、游戏、直播等专项 | 全部否 |
| 是否接入第三方 SDK | 否 |

> ⚠️ 备案时填写的**应用名称与包名必须与 AGC 创建应用时完全一致**，否则校验证件号/包名时不通过。

## 二、服务内容说明（可直接复制粘贴）

> 这一栏决定备案是否通过。下面这段按监管口径写，明确排除各类需前置审批的服务类型。

```text
青鸟传码是一款效率工具类移动应用，用于在用户自有的鸿蒙手机与 Windows 电脑之间，
通过同一局域网（Wi-Fi）点对点传输用户主动分享的短文本内容（如短信验证码、链接、
账号口令等）。应用仅提供文本传输与本地展示能力：手机端通过系统分享面板或剪贴板
获取用户主动选择的文本，经局域网发送至用户自行指定的电脑；配套的 Windows 接收端
程序自动识别其中的数字验证码、复制到剪贴板并弹出桌面通知。本应用不提供内容发布、
信息发布、社交互动、新闻资讯、交易支付、金融理财、医疗健康、教育培训等任何互联网
信息服务；不设有服务器端、不提供用户注册与登录、不运营网站或小程序；全部数据仅在
本机与用户自有局域网内处理，不上传、不存储于任何云端，不收集用户个人信息。
```

## 三、需要准备的材料

**个人主体**
- [ ] 身份证正反面照片
- [ ] 本人手机号（接收核验短信）
- [ ] 应急联系人手机号（部分表单要求）
- [ ] 已实名的华为开发者账号

**应用侧**
- [ ] 应用名称、包名（与 AGC 一致）
- [ ] 服务内容说明（见上）
- [ ] 隐私政策链接（已上线）
- [ ] 应用签名 MD5 指纹（AGC 备案页面通常会从已上传的软件包中读取）

## 四、常见退回原因

| 退回原因 | 规避方式 |
|---|---|
| 服务内容说明含糊或涉及专项服务 | 用上面那段，明确写“不提供……等互联网信息服务” |
| 应用名称/包名与 AGC 不一致 | 三处统一：AGC 应用、备案表单、Profile 绑定包名 |
| 隐私政策链接打不开 | 已用 GitHub Pages，公网可访问（提审前再点一次确认） |
| 主体信息与实名认证不符 | 用与华为开发者实名认证相同的证件 |

## 五、办理节奏

- 提交后由华为代提交至工信部系统，短信通知核验结果
- 一般 1–4 周出结果，期间可并行做版权认证与证书签名
- 拿到备案号后填回 AGC「版本信息 → 备案信息」，点“校验证件号”通过再提审
